Panduan Deploy ke GitHub Pages

Ikuti langkah-langkah mudah ini untuk membuat URL Shortener aktif secara penuh di GitHub Pages secara GRATIS:

1

Buat Repositori GitHub Baru

Buka GitHub, buat repository bernama sort-link (atau sesuai keinginan) dan atur ke Public.

2

Unggah File HTML ini sebagai index.html

Simpan kode file ini dengan nama index.html dan upload/commit ke repository utama.

3

Simpan File links.json di GitHub

Klik tombol "Ekspor links.json" di aplikasi ini, lalu unggah file links.json tersebut ke folder utama repositori GitHub Anda.

4

Aktifkan GitHub Pages

Masuk ke menu Settings > Pages di repo GitHub Anda. Pilih Branch main / root dan klik Save.

Cara Penggunaan Link Pendek: Pengunjung cukup membuka URL dengan parameter:
https://username.github.io/repo-name/?go=kodenya
Aplikasi akan membaca `links.json` dan otomatis mengarahkan ke URL tujuan!
