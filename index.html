Cara Deploy di GitHub Pages

Panduan langkah demi langkah

  1. Buat repositori baru di GitHub (contoh: sort-link).
  2. Upload file index.html ini ke repositori Anda.
  3. Buat link pendek di web ini, lalu klik tombol Ekspor links.json di pojok kanan atas.
  4. Upload file links.json tersebut ke repositori GitHub yang sama.
  5. Buka menu Settings > Pages di GitHub, pilih branch main, lalu simpan.
  6. Selesai! Akses link pendek Anda dengan format: https://username.github.io/sort-link/?go=kode-anda
